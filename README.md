# Aplikasi Android Sistem Deteksi Penyakit Tanaman Bawang Merah (2025)

Apilkasi ini merupakan hasil Tugas Akhir yang bertujuan untuk membantu untuk mendeteksi penyakit tanaman Bawang Merah menggunakan citra digital. Pengguna dapat mengunggah gambar melalui kamera atau galeri, kemudian aplikasi menampilkan hasil klasifikasi, tingkat akurasi, serta solusi pengendalian penyakit.

Aplikasi dikembangkan menggunakan Kotlin dan Jetpack Compose, serta memanfaatkan TensorFlow Lite untuk implementasi model deep learning di perangkat Android.
